# Manuscript for Mechanical Systems and Signal Processing (MSSP)

LaTeX sources of the manuscript *Blind band selection under pure decimation of bearing vibration:
aliased impulses, fault-order decisions and a power check for learned sampling*. The appendix
(`sections/appendix_ledger.tex`) lists the 35 pre-registered hypotheses, with the verdict and with
whether or not each one was committed before running, and gives the location in this repository of
the result files and exploratory scripts behind each section of the results.

The source archive of each release, which is what its Zenodo record keeps, leaves out the
manuscript text (`main.tex`, `sections/`, `highlights.txt` and this file). It keeps the generated
figures, tables and numbers.

**Structure:**

| Path | What it is |
|---|---|
| `main.tex` | title, abstract (up to 250 words), keywords, order of the sections |
| `sections/` | introduction, related work, methods, results, discussion, conclusion, appendix |
| `tables/` | tables generated by `papers/shared/figures/tab_*.py` |
| `figures/` | vector PDFs generated by `papers/shared/figures/fig_*.py` |
| `numbers/` | JSONs with the cited numbers, generated by `papers/shared/figures/num_*.py` |
| `highlights.txt` | the five Elsevier highlights, up to 85 characters each |
| `cover_letter.md`, `suggested_reviewers.md`, `submission_checklist.md` | cover letter, suggested reviewers and the steps of the submission system; kept out of the public repository |

**Figures:**

| Figure | Script | Content |
|---|---|---|
| `fig_valley_nested.pdf`, `fig_valley_local.pdf` | `fig_partA_valley.py --ruler nested\|local` | decimation valley on Ottawa (E20) |
| `fig_paderborn.pdf` | `fig_partA_paderborn.py` | replication on Paderborn (E24) |
| `fig_rule_paderborn.pdf` | `fig_rule_paderborn.py` | fault-order rule, acquisition and per-zone profile (E26, E26b, E26c) |
| `fig_masks_paderborn.pdf` | `fig_masks_paderborn.py` | learned masks under the two rulers (E15) |

Every curve has a 95 % bootstrap band over the independent units. Each script also writes a PNG to
the experiment's `figures/` directory, for the Markdown reports. `fig_rule_paderborn.py` and
`fig_masks_paderborn.py` check the points against the analysis files of the run and stop if
anything diverges.

**How to compile,** with a minimal TeX Live (TinyTeX) installed only in this repository, in
`.tools/`, outside git and outside the system PATH:

```
uv run python papers/shared/build_pdf.py install                 # once: TinyTeX and packages
uv run python papers/shared/build_pdf.py build papers/mssp-2026  # main.pdf, with the pending items
uv run python papers/shared/build_pdf.py build papers/mssp-2026 --submission  # main-submission.pdf
```

Both PDFs are generated and are not versioned. `main-submission.pdf` is the version for the
journal: without the list of pending items and without the `todonotes` boxes. The references are
numbered in order of citation (`elsarticle-num-names`), the MSSP style. The bibliography is the
single source, `../../literature/refs.bib`, and the text only cites entries with a `verified`
field.

**How to package the submission:**

```
uv run python papers/shared/pack_submission.py papers/mssp-2026
```

It writes `submission/`, which is not versioned:
- `Manuscript.pdf`;
- `LaTeX_source.zip`, with the sources in a single folder, since Elsevier's LaTeX compiler cannot
  process subfolders. It includes `main.bbl` and a `refs.bib` reduced to the cited entries;
- `Highlights.txt`;
- `Cover_letter.pdf`, when `cover_letter.md` is present;
- `declarationStatement.docx`, the Word file of Elsevier's declaration tool, when it is saved in this
  folder (git ignores it);
- `suggested_reviewers.md`, when present;
- `Checklist.md`, when `submission_checklist.md` is present: the steps of the submission system, with
  the title, abstract, keywords, authors and statements of `main.tex` as plain text for the web
  forms.

The script compiles the flat sources once with the shipped `main.bbl` and once with BibTeX. It stops
if either compile differs from `main-submission.pdf`.
