**Structure:**

| Path | What it is |
|---|---|
| `main.tex` | title, abstract (up to 250 words), keywords, order of the sections |
| `sections/` | introduction, related work, methods, results, discussion, conclusion, appendix |
| `tables/` | tables generated by `papers/shared/figures/tab_*.py` |
| `figures/` | vector PDFs generated by `papers/shared/figures/fig_*.py` |
| `numbers/` | JSONs with the cited numbers, generated by `papers/shared/figures/num_*.py` |
| `highlights.txt` | the five Elsevier highlights, up to 85 characters each |

Every curve has a 95 % bootstrap band over the independent units. Each script also writes a PNG to
the experiment's `figures/` directory, for the Markdown report. The two new scripts check the
points against the analysis files of the run and stop if anything diverges.

**How to compile,** with a minimal TeX Live (TinyTeX) installed only in this repository, in
`.tools/`, outside git and outside the system PATH:

```
uv run python papers/shared/build_pdf.py install                 # once: TinyTeX and packages
uv run python papers/shared/build_pdf.py build papers/mssp-2026  # main.pdf, with the pending items
uv run python papers/shared/build_pdf.py build papers/mssp-2026 --submission  # main-submission.pdf
```

Both PDFs are generated and are not versioned. `main-submission.pdf` is the version for the
journal: without the list of pending items and without the `todonotes` boxes. The references are
numbered in order of citation (`elsarticle-num-names`), the MSSP style. The bibliography is the
single source, `../../literature/refs.bib`, and the text only cites entries with a `verified`
field. The internal notes of the entries go in the `annote` field, which the Elsevier style does
not print.
